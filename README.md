# Safiri Nasi — Tour & Travel

Booking platform for Safiri Nasi Tour & Travel: tour showcase, online booking, payments (M-Pesa, Airtel Money, card via DPO Pay), record keeping and an admin panel.

- `frontend/` — Next.js (App Router, TypeScript, Tailwind)
- `backend/` — FastAPI (SQLAlchemy, Alembic, PostgreSQL)

Setup instructions are being written as the project is built.
